# MathRecall

Локальное веб-приложение для изучения университетской математики с интервальным повторением FSRS.

**Статус:** MVP 0.2. Поддерживается macOS; проверено на Mac с Apple Silicon. Windows и Linux пока не поддерживаются и не тестируются.

## Возможности

- Предметы, вложенные темы, экзаменационные билеты и связанные карточки.
- Три типа карточек: определение, доказательство и задача.
- Редактор Markdown и LaTeX с предпросмотром KaTeX и пошаговыми подсказками.
- FSRS с четырьмя оценками: «Снова», «Трудно», «Хорошо», «Легко». Карточка в нескольких билетах сохраняет общее расписание.
- План повторений на сегодня, поиск, фильтры и статистика.
- Импорт карточек из JSON: проверка, очередь черновиков, редактирование, отклонение, выборочное и массовое принятие, объединение дубликатов.
- Промпт для генерации совместимого JSON во внешнем ChatGPT, ссылки на страницы источников.
- Хранение в IndexedDB, экспорт и восстановление резервной копии.
- Тёмная и светлая темы, адаптивный интерфейс, офлайн-режим готовой сборки.

Сервер приложения, аккаунт и API-ключи не нужны. Учебные данные остаются в браузере.

## Установка на macOS

Нужны **Node.js 24** (также совместим Node.js 22.12+) и **pnpm 11.25.0**. Установите Node.js, затем в Terminal:

```sh
npm install --global pnpm@11.25.0
```

Склонируйте репозиторий, перейдите в его папку и установите зависимости:

```sh
pnpm install --frozen-lockfile
```

Для первой установки зависимостей нужен интернет.

## Запуск

В папке проекта выполните:

```sh
./start.command
```

Можно также открыть `start.command` двойным нажатием в Finder. Скрипт проверяет TypeScript, собирает приложение и запускает локальный preview. Откройте **http://127.0.0.1:4173/**. Для остановки нажмите `Ctrl+C` в окне Terminal.

Если порт занят, остановите предыдущий экземпляр. Другой порт можно указать через `MATHRECALL_PORT`, но для браузера это будет отдельная библиотека.

Для разработки с автоматическим обновлением страницы:

```sh
pnpm dev
```

Vite покажет адрес, обычно `http://127.0.0.1:5173/`. Не открывайте `index.html` через `file://`.

## Работа с карточками

Создайте предмет, тему и билет в библиотеке, затем добавьте карточку. В повторении сначала вспомните ответ, при необходимости раскройте подсказки, покажите ответ и поставьте оценку. Дата следующего повторения рассчитывается FSRS и сохраняется вместе с историей.

Формулы в строке записываются как `$a_n \to a$`. Для отдельной формулы поставьте `$$` на строках до и после неё. Подсказки в редакторе разделяются пустой строкой.

Клавиши в повторении: **Space** — показать ответ, **1–4** — оценить. План на сегодня включает карточки до конца суток; повторение доступно после наступления их срока, с учётом дневного лимита новых карточек. Карточка с коротким шагом FSRS снова появится в очереди в назначенное время.

## Импорт JSON

Откройте «Импорт карточек». Можно загрузить файл или вставить JSON, а также скопировать промпт для внешнего ChatGPT. Все записи сначала попадают в черновики и включаются в обучение только после принятия. Совпадения объединяются без перезаписи истории FSRS.

- [JSON Schema](public/formats/mathrecall-card-exchange.v1.schema.json)
- [Пример JSON](public/formats/mathrecall-card-exchange.v1.example.json)
- [Описание формата и правил объединения](docs/CARD_EXCHANGE.md)

**Обмен карточками** (`MathRecall.CardExchange`, version 1) и **резервная копия** (`MathRecall`, version 1) — разные форматы. Резервная копия восстанавливается в настройках и заменяет библиотеку после подтверждения. Черновики в неё не входят; они сохраняются отдельно и не удаляются при восстановлении библиотеки.

Пользовательские файлы `*.json`, `*.jsonl` и `*.ndjson` по умолчанию исключены из Git, в том числе во вложенных папках. Для собственных материалов удобно использовать `imports/` или `backups/`. В репозитории остаются только служебные JSON-конфигурации, схема и публичный пример. Импорт через интерфейс хранит данные в IndexedDB, а не в исходниках.

## Хранение и офлайн-режим

Данные привязаны к конкретному браузеру и адресу, включая порт. Например, `localhost:5173` и `127.0.0.1:4173` имеют разные базы. Переносите библиотеку через JSON-копию. Очистка данных браузера и приватный режим могут привести к потере локальной библиотеки.

Для работы без сети один раз загрузите готовую сборку с запущенным preview и дождитесь в настройках статуса «Готово к работе без сети». Офлайн-кэш отключён в режиме разработки. После обновления сборки закройте старые вкладки приложения и откройте его заново.

## Разработка и проверки

```sh
pnpm test
pnpm build
pnpm format:check
```

Тесты покрывают CRUD, связи, миграцию базы, FSRS, сохранение истории, резервные копии, импорт, черновики, дубликаты и безопасный рендеринг формул. Для обновления опубликованных схемы и примера после изменения формата:

```sh
pnpm generate:exchange
```

Стек: React, TypeScript strict, Vite, Tailwind CSS, Lucide, KaTeX, Dexie, ts-fsrs, Zod и Vitest.

Основные части проекта:

- `src/components/` — интерфейс, редакторы и повторение.
- `src/services/` — работа с библиотекой, FSRS и резервными копиями.
- `src/import/` — формат обмена, валидация, черновики и принятие.
- `src/db.ts`, `src/model.ts` — схема IndexedDB и модели.
- `src/test/` — автоматические тесты.

## Ограничения

Пока нет встроенной ИИ-генерации, извлечения текста/PDF, OCR, авторизации, облачной синхронизации, изображений в карточках и отмены оценки. Билеты связаны с карточками своей темы. Дубликаты определяются по предмету, пути темы, типу, вопросу и ответу; семантическое сравнение не выполняется. Поддержка других операционных систем пока не предусмотрена.
