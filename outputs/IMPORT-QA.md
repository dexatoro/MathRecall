# MathRecall 0.2 · проверка JSON-импорта

25 октября 2026, macOS Apple Silicon. Без расширения Chrome, платных API и авторизации.

## Автоматические проверки

74/74 теста Vitest: прежние 37 сценариев и 37 новых проверок импорта.

- Соответствие опубликованных JSON Schema и примера исходным Zod-схемам, правильное экранирование LaTeX в промпте.
- Все три типа, подсказки, Unicode, inline/block формулы; страницы источников и безопасные http/https-ссылки.
- Невалидный JSON, пропущенные и неизвестные поля, неподдерживаемые версии, ошибочная попытка загрузить backup, неверные страницы и URL, ограничения размера и количества карточек.
- Постоянное хранение черновиков до принятия, редактирование с проверкой ревизии, отклонение и возврат, выборочное и массовое принятие.
- Переиспользование предметов, вложенных тем и билетов; отсутствие перезаписи описаний.
- Дубликаты внутри и между пакетами, сохранение регистра математических символов, объединение связей без изменения карточки, FSRS или истории.
- Повторное и конкурентное принятие, атомарный откат ошибки записи.
- Сценарий JSON → черновик → принятие → очередь FSRS → оценка → сохранение.
- Миграция Dexie v1 → v2 на реальных карточках/состояниях/логах в fake-indexeddb; восстановление backup v1, сохранность очереди черновиков и прежних полей формата.

TypeScript strict, production build и Prettier check проходят.

## Браузерная проверка через интерфейс

1. Сформирован тестовый JSON по опубликованному примеру: определения, доказательство, задача, страницы источника, вложенные темы и одна точная копия определения.
2. Невалидная вставка показала пути ошибок `cards[0].…` без изменения библиотеки.
3. JSON-файл загрузился через выбор файла: в очереди 4 черновика; до принятия они не включены в обучение.
4. Предпросмотр отрисовал LaTeX и ссылку `#page=12` с диапазоном страниц 12–14.
5. В редакторе добавлена подсказка и сохранена именно в черновик.
6. Задача отклонена и возвращена на проверку через фильтр.
7. Флажком выбрано и принято одно доказательство; массовым принятием остальных созданы ещё 2 карточки и объединён 1 дубликат. Итого 3 карточки, 4 уровня/узла тем, 2 билета в тестовом предмете «Импорт · Проверка JSON».
8. Все три принятые карточки прошли повторение. Сохранены три оценки, источник со страницами и добавленная подсказка.
9. После перезагрузки отображается 3 карточки в режиме повторения; прежние 2 оценки библиотеки остались на месте, общий счётчик равен 5.
10. Тот же JSON вставлен в текстовое поле через буфер и принят ещё раз: создано 0 карточек, объединено 1 совпадение.
11. Ошибок в консоли страницы не обнаружено.

Кнопки генерации промпта и вставки буфера вызваны в браузере. Для автоматического копирования/чтения используются browser Clipboard API; если браузер блокирует доступ, доступны отдельное окно промпта и обычная ручная вставка. Встроенный браузер не позволил независимо подтвердить системное содержимое буфера после Clipboard API; точное содержимое генерируемого промпта проверено тестом. Вставка JSON через буфер в поле проверена непосредственно.

Снимки: `import-drafts.jpg` — очередь с дубликатом и выбором; `import-review.jpg` — принятая карточка в повторении, LaTeX и ссылка на страницу источника.

## Ограничения

Нет встроенной генерации, платных запросов, PDF-разбора, авторизации и синхронизации. Генерация тестового JSON выполнялась локально по схеме; внешний ChatGPT не вызывался. Поиск дубликатов детерминированный, без семантического сравнения. Различия только в подсказках и источниках не перезаписывают существующую карточку. Черновики и журнал импортов не входят в backup v1; они остаются в IndexedDB и переживают восстановление самой библиотеки.
