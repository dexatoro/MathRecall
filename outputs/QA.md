# MathRecall 0.1 · Проверки первой итерации

Дата: 25 октября 2026. macOS Apple Silicon, Node 24.22.1. Код: React + TypeScript strict + Vite + Tailwind, Dexie, ts-fsrs 5.4.2, KaTeX.

## Автоматизация

- 37/37 тестов Vitest: нормализованный CRUD, три типа карточек, дерево тем, общие карточки билетов, все оценки FSRS, история и следующее повторение, сохранение при закрытии/открытии IndexedDB, защита конкурирующих оценок, дневной лимит, резервные копии, валидация и откат транзакции.
- Проверены Markdown, inline/block KaTeX и отключение произвольного HTML, JS-ссылок, внешних изображений и опасных команд формул.
- `pnpm build`: TypeScript strict + production build успешно.
- `pnpm format:check`: исходники отформатированы Prettier.

IndexedDB в Vitest проверяется через fake-indexeddb. Дополнительно постоянство данных проверено в настоящем браузере.

## Браузерные сценарии

1. Создан предмет «Проверка · Математический анализ».
2. Создана тема «Последовательности» и билет «Предел монотонной последовательности».
3. В билете создана карточка с определением предела, LaTeX, блочной формулой, подсказкой и источником. Предпросмотр рисует KaTeX.
4. В повторении раскрыта подсказка, затем ответ. Показаны прогнозы четырёх оценок: 1 мин, 6 мин, 10 мин, 8 дней для тестовой новой карточки при retention=0.9.
5. Выбрано «Легко». После перезагрузки сохранены: состояние «Повторение», один review, один связанный билет, следующая дата 02.11.2026 20:07:05 по Москве. См. `review-persisted.jpg`.
6. Создана карточка-доказательство; она сразу появилась в доступной очереди. Оценка «Хорошо» сохранена клавишей 3, назначен шаг через 10 минут.
7. Проверена ширина 390×844: одноколоночная библиотека, отсутствие горизонтального переполнения, открытие и закрытие меню. См. `mobile.jpg`.
8. На отдельном чистом origin загружен production-кэш. Локальный сервер остановлен. После перезагрузки приложение полностью открылось без сервера и ошибок консоли; добавлены три демо-карточки в IndexedDB и скачан JSON через интерфейс. См. `offline-dashboard.jpg`.

## Что исправлено по проверкам

- Цикл зависимостей при первоначальном разделении production-bundle, вызывавший пустой экран.
- Устаревшее текущее время после сохранения карточки, задерживавшее её появление в очереди.
- Мобильная область закрытия меню и доступность скрытой навигации.
- Поиск ресурсов в Service Worker при `Vary: Origin`, из-за которого module scripts не находились в офлайн-кэше.
- Нестабильный тест, случайно выбирающий тот же предмет по порядку UUID.

## Границы проверки

Ни ИИ, ни импорт PDF/конспектов, ни авторизация/синхронизация не реализованы в этом этапе. Полного автоматизированного browser E2E набора пока нет: браузерные сценарии выполнены через интерфейс, основные инварианты покрыты Vitest. JSON import/export round-trip и атомарность проверены автоматическими тестами; скачивание JSON — также в браузере.
